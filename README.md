# Manthan Jain — Personal Portfolio & Cinematic Web App

[![Build Status](https://img.shields.io/badge/status-active-success.svg)](#)
[![Stack](https://img.shields.io/badge/stack-HTML5--CSS3--JS-blue.svg)](#)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](#)

A high-performance, scroll-driven interactive portfolio showcasing work in **Agentic AI**, **Sustainable Innovation**, and **Strategic Growth**. Built with raw HTML5, custom CSS design system, and an ultra-high-definition 2D canvas video motion engine.

---

## ✨ Features

- **Scroll-Linked Motion Canvas**: 300 pre-rendered high-definition video frames synchronized seamlessly with window scroll progress.
- **Ultra-HD Canvas Rendering**: Dynamic Device Pixel Ratio scaling (up to `2.5x`), bi-cubic image smoothing (`imageSmoothingQuality = 'high'`), and pixel-perfect 1:1 image framing.
- **Cinematic Dark Design System**: Glassmorphism (`backdrop-filter`), ambient radial lighting, subtle SVG grain texture (`opacity: 0.025`), and curated typography (*Instrument Serif*, *DM Sans*, *DM Mono*).
- **Responsive & Accessible**: Optimized for mobile, tablet, and HiDPI desktop screens with complete `prefers-reduced-motion` compliance.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design Tokens), ES6+ JavaScript
- **Canvas Engine**: HTML5 Canvas API (scroll-linked frame interpolation)
- **Typography**: Google Fonts (*DM Sans*, *DM Mono*, *Instrument Serif*)

---

## ⚡ Quick Start

No build tools or bundlers required. Run locally using any HTTP server:

```bash
# 1. Clone the repository
git clone https://github.com/MJforti/portfolio.git
cd portfolio

# 2. Start a local server (Python 3)
python -m http.server 8080

# 3. Open in browser
open http://localhost:8080
```
